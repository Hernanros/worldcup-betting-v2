## Task 1 — Inline Prediction on Home

### Goal
Tap the NextMatchHero "Predict" button → score pickers appear inline in the hero card. No navigation to /predict. After saving, hero collapses and shows the saved score. Dare button continues to navigate to the match challenge tab.

### Architecture

**Data flow in `HomePage`:**
- Add `/api/predictions` to the existing parallel `load()` fetch.
- Find the entry where `entry.match_id === nextMatch.id` → pass as `myPrediction` prop to `NextMatchHero`.
- `handlePredSaved(newDoublesCount)` callback: call `load()` to refresh so the hero reflects the updated prediction.

**New props on `NextMatchHero`:**
```
match              — existing
navigate           — existing
myPrediction       — {home_score_pred, away_score_pred} | null
onPredSaved(count) — called after successful save
```

**New state inside `NextMatchHero`:**
```
predExpanded  boolean  — controls whether HeroScorePicker is shown
```

**Button states:**

| State | Left button | Right button |
|---|---|---|
| No prediction, collapsed | `⚔️ Dare friends` → navigate | `🎯 Predict` → set predExpanded=true |
| Expanded | `⚔️ Dare friends` → navigate | `✕ Cancel` → set predExpanded=false |
| Has prediction, collapsed | `⚔️ Dare friends` → navigate | `🎯 {H}–{A} · change` → set predExpanded=true |

**New sub-component: `HeroScorePicker`**

Location: defined inline inside `NextMatchHero` (no separate file — it's a thin component tied to the hero UI).

Props:
- `entry` — same shape as PredictionRow entry (`{match_id, home_team, away_team, kickoff_time, my_prediction, status}`)
- `onSaved(doublesCount)` — called on successful API save
- `onCollapse()` — called after save to close the picker

State: `home`, `away` (nullable ints), `activePicker` ("home"|"away"|null), `saving`, `msg`.

Behaviour:
- Two score input boxes (same `scoreInputStyle` logic as `PredictionRow`)
- Number grid 0–9 (same as `PredictionRow`'s NUM_PICKER)
- Auto-saves via `POST /api/predictions` when both home and away are filled
- On success: calls `onSaved(result.doubles_used)` then `onCollapse()`
- No doubles button, no urgency badge, no clear button — keep it minimal

### What is NOT changing
- PredictionRow and PredictionsPage are unchanged
- The full Predictions page (/predict) still exists for the full list view

## Task 4 — Text Size Sweep

### Goal
Case-by-case audit of all inline `fontSize` values. Bump under-readable text; preserve intentional micro-labels.

### Rules

| Category | Current | Action |
|---|---|---|
| Team names in rows/cards | 11px | Bump to 13px |
| Button labels (action CTAs) | 12px | Bump to 13px |
| Description text / reasons | 12px | Bump to 13px |
| Section headers (UPPERCASE) | 9–10px | Keep — intentional hierarchy |
| Badge/pill meta (group, time) | 8–10px | Keep — intentional |
| Count indicators, streak numbers | 9–10px | Keep |
| Secondary labels ("Their pick", "Stake") | 10px | Keep — they sit beneath larger primary text |

### Scope
All `.jsx` files in `frontend/src/pages/` and `frontend/src/components/`. Grep `fontSize: 11` and `fontSize: 12` instances, review each in context, apply bumps where the text is primary content.

### Key files likely to need changes
- `ChallengePanel.jsx` — suggestion reason text at 12, team name labels
- `PredictionRow.jsx` — team name spans at 11
- `DailyFeed.jsx` — moment text at 11, team names at 11
- `HomePage.jsx` — dare/challenge description text at 12

## Task 3 — Daily Feed Expansion

### Goal
Add 3 new moment types to the daily feed: `bet_win` (regular BetPanel wins), `streak` (prediction win streaks), `deep_cut` (Deep Cuts/SpicyBet wins).

### Backend changes (`routers/feed.py`)

**New imports:** `Bet`, `SpicyBet` from `app.models`.

**1. `bet_win` moments**

Note: `Bet` has no `payout` column — calculate as `round(b.stake * b.odds_at_placement)`.

```python
bets_won = await db.execute(
    select(Bet).where(
        Bet.match_id.in_(finished_ids),
        Bet.player_id.in_(league_player_ids),
        Bet.status == "won",
    )
)
for b in bets_won.scalars().all():
    m = match_by_id.get(b.match_id)
    if not m: continue
    moments.append({
        "type": "bet_win",
        "player": name_of.get(b.player_id, "Someone"),
        "match": f"{m.home_team} vs {m.away_team}",
        "selection": b.selection,
        "payout": round(b.stake * b.odds_at_placement),
        "is_me": b.player_id == player.id,
    })
```

**2. `deep_cut` moments**

`SpicyBet` is stage-level (no `match_id`). To scope it to "today," we need a `settled_at` timestamp:

**Schema change required:** Add `settled_at = Column(DateTime, nullable=True)` to `SpicyBet` in `models.py`.

**Settlement change required:** In `deep_cuts_settlement.py`, when setting a SpicyBet's status to "won" or "lost", also set `bet.settled_at = datetime.utcnow()`.

Then in `feed.py`:
```python
deep_wins = await db.execute(
    select(SpicyBet).where(
        SpicyBet.player_id.in_(league_player_ids),
        SpicyBet.status == "won",
        SpicyBet.settled_at >= datetime.combine(today_utc, time.min),
        SpicyBet.settled_at <  datetime.combine(today_utc, time.max),
    )
)
for b in deep_wins.scalars().all():
    payout = round(b.stake * b.odds_at_placement)
    moments.append({
        "type": "deep_cut",
        "player": name_of.get(b.player_id, "Someone"),
        "market_key": b.market_key,
        "selection": b.selection,
        "payout": payout,
        "is_me": b.player_id == player.id,
    })
```

Import `time` from stdlib for `time.min` / `time.max`, and `datetime.combine`.

**3. `streak` moments**
For each league player, fetch their last 8 settled predictions ordered by `match_id` descending. Count the consecutive head run of `correct_score` or `correct_outcome`. If streak ≥ 3 AND the player's most recent settled prediction is from today's `finished_ids`, emit one streak moment.

Milestones: 3, 5, 10 (emit only at these exact values to avoid duplicate flooding).

```python
from sqlalchemy import and_

for pid in league_player_ids:
    recent = (await db.execute(
        select(Prediction)
        .where(
            Prediction.player_id == pid,
            Prediction.status.in_(["correct_score", "correct_outcome", "wrong"]),
        )
        .order_by(Prediction.match_id.desc())
        .limit(12)
    )).scalars().all()
    
    streak_len = 0
    for pred in recent:
        if pred.status in ("correct_score", "correct_outcome"):
            streak_len += 1
        else:
            break  # consecutive run broken
    
    # Only emit if streak extended today and hits a milestone
    todays_preds = {p.match_id for p in recent if p.match_id in set(finished_ids)}
    if streak_len in (3, 5, 10) and todays_preds:
        last_match = match_by_id.get(recent[0].match_id)
        moments.append({
            "type": "streak",
            "player": name_of.get(pid, "Someone"),
            "streak": streak_len,
            "match": f"{last_match.home_team} vs {last_match.away_team}" if last_match else "",
            "is_me": pid == player.id,
        })
```

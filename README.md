# ⚽ World Cup Betting — Player Guide

> A private P2P prediction game for the 2026 World Cup.
> No real money. Just bragging rights and tokens.

---

## 🚀 Getting started

1. Open the app link (your host will share it)
2. Enter your name + the invite code
3. You start with **1 000 tokens** — use them wisely

---

## 🎮 What you can do

### 🏆 Predict scores
Before every match, pick the exact score.

| Result | Points |
|--------|--------|
| Exact score (e.g. 2–1) | **+3 pts** |
| Correct winner / draw | **+1 pt** |
| Wrong | 0 |

---

### 💰 Place match bets
Bet tokens on a match outcome before kick-off.

```
Argentina to win  ×1.40  →  stake 200  →  win 280
```

> Betting closes automatically at kick-off.

Supported markets: **Match result · Both teams to score · Goals over/under · Correct score · Corners · Yellow cards · Red cards · Asian handicap**

---

### ⚔️ Issue P2P challenges
Call out another player directly.

1. Go to any upcoming match → **Challenges**
2. Pick your side, set stake and odds
3. Another player accepts → tokens locked
4. Match ends → winner gets both stakes

```
Alice:  England   100t @ 1.30
Bob:    Iran       14t @ 9.00
→ England wins → Alice collects 130t
```

---

### 🤖 AI suggestions
Not sure what to bet? Hit **AI Assistant**, pick a match, and Claude will suggest two challenge ideas with picks, odds, and reasoning.  
Tap **Issue This Challenge →** to open the challenge form pre-filled.

---

## 🔥 Bravery streaks

Issue challenges consistently and earn **win bonuses**:

| Streak | Bonus |
|--------|-------|
| 3 in a row | +10% on winnings |
| 4 in a row | +20% on winnings |
| 5+ in a row | +35% on winnings |

Losing a challenge **resets** your streak.

## 📊 Rankings

The leaderboard combines **token balance + prediction points**.  
Check the Rankings tab to see where you stand.

---

## ❓ Quick rules

- You can't accept your own challenge
- Open challenges are cancelled if you don't have enough tokens at kick-off
- Predictions can be updated any time before the match is locked
- Tokens can't go below 0 — you can only bet what you have

Key design decisions

🔌 WebSockets
Live score updates push to all connected clients the moment the poller settles a match. Leaderboard refreshes automatically.
🤖 AI streaming
Claude reads match odds + your balance and streams challenge suggestions. Typewriter effect — feels instant, not "loading...".
⏱ Auto-poller
Background asyncio task fetches scores every 60s during live matches, auto-settles bets & challenges, propagates KO winners.
🌱 DB init script
Since there's no admin UI, a CLI seed script imports matches + seeds the KO bracket on first deploy. Run once, done.
